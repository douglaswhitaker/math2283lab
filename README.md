# math2283lab

This R package contains functions that are used in MATH 2283 (Introduction to Nonparametric Statistics) at MSVU. It is not intended to be useful outside of this context, and documentation is not to the standard of a package made for public release. 

Currently this package serves two purposes:

* Generating data from known distributions (parameter values based on specific journal articles)
* Performing simulations to compare estimators and methods with little need for interaction

The `other/lab4-loader.R` file contains the instructions for installation.
